# Cyber-Home OS | ESP8266 Smart Home Automation System

1. Cyber-Home OS is an IoT-based smart home automation and security system built using the ESP8266 NodeMCU.

2. The ESP8266 creates its own WiFi access point and hosts a local web dashboard that allows wireless control and monitoring of connected devices in real time.

3. The system includes:

   * Smart door lock control using a servo motor
   * Light control
   * Fan speed control using PWM
   * Temperature monitoring using an LM35 sensor
   * Intruder detection using an ultrasonic sensor
   * Buzzer-based alert system

4. The dashboard is built using HTML, CSS, and JavaScript with a cyber-themed interface and live status updates.

5. This project demonstrates practical implementation of:

   * IoT communication
   * Embedded web servers
   * Sensor and actuator integration
   * Real-time monitoring and automation

6. Technologies used:

   * ESP8266 NodeMCU
   * Arduino Framework (Embedded C++)
   * ESP8266WebServer Library
   * Servo Library
